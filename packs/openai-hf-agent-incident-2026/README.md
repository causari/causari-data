# OpenAI–Hugging Face Agent Incident 2026

Golden incident pack for the Causari Event Explorer.

This pack deliberately separates five layers:

1. events — what happened;
2. claims — what can be asserted about those events;
3. evidence — provenance-backed support;
4. causal links — typed, confidence-scored relations between events;
5. forecasts — resolvable future hypotheses.

The central modeling rule is: **chronology is not causality, and interpretation is not observation**.
